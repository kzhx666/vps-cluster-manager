添加 VPS 主机

自定义该台 VPS 的个性化设置 (NAT端口、专属域名、Argo 隧道等)。

1. SSH 连接信息
2. 订阅源名称 (TAG 标签)
Reality / Hy2 / TUIC 三合一聚合到该订阅源

3. 端口规划模式 (解决 NAT VPS 端口受限痛点)
💡 自动规划分配: Reality=10020, Hy2=10021, TUIC=10022, xHTTP=10023, AWG=10024, Hy2跳跃池=10025-10039
4. 专属 TLS 证书域名与 Reality 伪装目标

5. Cloudflare Argo 隧道穿透 (可选)

批量导入 VPS 主机

支持多行批量粘贴，自动解析 IP、SSH端口、用户与密码。

# 格式 1: IP:端口:用户:密码 (例如: 1.2.3.4:22:root:MyPass123) # 格式 2: IP:密码 (默认端口 22, 用户 root) # 格式 3: 用户:密码@IP:端口 (例如: root:MyPass123@1.2.3.4:22022) # 格式 4: IP 端口 用户 密码 (空格分隔) # 格式 5: 自定义名称:IP:端口:用户:密码 (例如: 香港1区:1.2.3.4:22:root:Pass123) # 格式 6: IP:端口:用户:密码:自定义名称 (例如: 1.2.3.4:22:root:Pass123:香港1区)
💡 若单行文本内未指定名称，将自动使用此名称并递增编号；若单行已包含名称则优先使用单行名称。
